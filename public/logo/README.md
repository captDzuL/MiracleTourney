# Miracle logo assets

Master: logo M besar pada panel kiri atas brand board yang diberikan pengguna. Cyan di kiri, violet di kanan; wordmark cream.

SVG merupakan rekonstruksi vektor dari referensi raster, bukan file sumber desain asli. Kontur utama, potongan diagonal, dan karakter wordmark ditelusuri ulang. Detail kurva huruf dan gradasi dapat sedikit berbeda dari raster. Seluruh huruf sudah berupa path; tidak membutuhkan font.

- miracle-symbol.svg: simbol saja.
- miracle-horizontal.svg: simbol dan MIRACLE.
- PNG 2048 dan 4096: ekspor langsung dari SVG, transparansi alpha asli, ukuran mengacu pada lebar.
- miracle-preview.png: pratinjau dengan latar gelap, bukan aset transparan.

Warna: cyan/blue, violet/purple, cream #F6DFB1. Stop gradasi merupakan perkiraan visual dari referensi, bukan kode HEX resmi.

Sisakan ruang bebas minimal kira-kira selebar batang vertikal M di sekitar logo. Gunakan SVG untuk cetak atau ukuran lebih besar.
